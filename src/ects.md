has moved to a <a href="https://webhomes.maths.ed.ac.uk/~mwoolf/ects/">new home</a>. This page will continue to be available for some time for archival purposes.</p>

The Edinburgh category theory seminar runs on most termtime **Wednesdays from 12:05 to 13:00** in the **Bayes Centre, Room 5.46**. Most talks will also be livestreamed via MS Teams. Please note that we won't be meeting on strike days.

The seminar is intended to be an informal environment where people interested in category theory can share ideas. Most of our speakers are internal, with some occasional guests. Talks span a wide range of topics, from derived algebraic geometry to theoretical computer science, so they should be accessible to anyone with some category theory basics. There is no requirement to talk about cutting-edge research, and, in particular, PhD students should feel comfortable giving an introductory talk on some standard categorical topic.

This is one of several seminars run within the Hodge Institute at Edinburgh. The details of these can be found on the [Hodge seminars website](https://sites.google.com/view/hodge-seminars/).

For more details, or to propose a talk, please email [Adrián](/) or [Tom](https://webhomes.maths.ed.ac.uk/~tl/). The old website for the Edinburgh category theory seminar can be found [here](https://webhomes.maths.ed.ac.uk/~emilyroff/late_lunch.html).
