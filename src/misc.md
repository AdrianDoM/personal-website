## Coding
- I mechanised the theory of strict ω-categories in Isabelle/HOL. It is now a part of the [Archive of Formal Proofs](https://devel.isa-afp.org/entries/StrictOmegaCategories.html).
- [Here](https://github.com/AdrianDoM/IMOinLEAN) is some of the maths I mechanised in Lean for my undergraduate Honours Project.
- I created some [fun visual sketches](https://adriandom.github.io/p5js-lab/) using the [Processing](https://processing.org/) JS library a long time ago.
- I made a barebones JS implementation of the NEAT (NeuroEvolution of Augmenting Topologies) algorithm by Ken Stanley and Risto Miikkulainen in JS which can be found [here](https://github.com/AdrianDoM/neat-js).
